Pensamiento Computacional y Métodos de Solución

Glosario Técnico:

  • Pensamiento Computacional: Proceso mental de formular un problema y su solución de manera que un humano o una máquina puedan ejecutarla de forma efectiva.
  • Abstracción: Ignorar los detalles irrelevantes de un problema para centrarse solo en lo importante.
  • Divide y Vencerás (Top-Down): Técnica militar y computacional de tomar un problema inmenso y dividirlo en sub-problemas más pequeños y fáciles de resolver.

5 Ejercicios Prácticos:

  2. Pensamiento Algorítmico: Escribe en tu libreta el algoritmo exacto paso a paso (mínimo 10 pasos) para cambiar la llanta de un auto. Numéralos.

  5. Lógica Secuencial: Desordena los pasos para preparar un sándwich. Pídele a un compañero que intente hacerlo siguiendo tu orden incorrecto para entender la importancia de la secuencia.
RA 2.1

Técnicas de Diagramación y Método 5E

Glosario Técnico:

  • Método 5E: Modelo de aprendizaje constructivista (Enganche, Explorar, Explicar, Elaborar, Evaluar).
  • Diagrama de Flujo: Representación gráfica de un proceso o algoritmo. Usa símbolos estandarizados (ISO) conectados por flechas.
  • Software de Modelado: Herramientas digitales como PSeInt, Lucidchart o Blockly que permiten dibujar diagramas arrastrando bloques lógicos.

Simbología Estándar de Diagramas:

graph TD A([Óvalo: INICIO / FIN]) --> B[/Paralelogramo: Entrada o Lectura de Datos/] B --> C[Rectángulo: Proceso o Cálculo Matemático] C --> D{Rombo: Decisión Lógica SI/NO} D -- SI --> E[/Documento: Salida por Pantalla/] D -- NO --> A

5 Ejercicios Prácticos (Entregables RA 2.1):

  3. Decisión Lógica (Rombo): Diseña un diagrama de flujo para un sistema de semáforo. Si es ROJO, detenerse; Si es VERDE, avanzar.
  4. Uso de PSeInt: Descarga PSeInt. Escribe un pseudocódigo que pida tu nombre y lo imprima. Haz clic en el botón "Dibujar Diagrama de Flujo" para ver cómo el programa lo genera automáticamente.
  5. Modelo 5E Aplicado: Elige un problema de tu entorno (ej. Mucha basura en el salón). Desarrolla la propuesta de solución aplicando las etapas: Enganchar, Explorar, Explicar, Elaborar (Diagrama de la solución) y Evaluar.
RA 2.2

Fundamentos: Datos, Variables y Constantes

Glosario Técnico:

  • Variable: Un espacio reservado en la memoria RAM que tiene un nombre y guarda un valor que puede cambiar durante la ejecución del programa (ej. vidas_jugador = 3).
  • Constante: Un espacio en memoria cuyo valor nunca cambia. (ej. PI = 3.1416).
  • Tipos de Datos: Determinan qué se guarda en la variable. Pueden ser Numéricos (Enteros/Decimales), Cadenas de Texto (String) o Lógicos (Booleanos: Verdadero/Falso).

Ejemplo en Código (Python):

# Declaración de variables en Python
nombre = "María"      # Dato String (Texto)
edad = 16             # Dato Integer (Entero)
estatura = 1.65       # Dato Float (Decimal)
es_estudiante = True # Dato Booleano

5 Ejercicios Prácticos:

  1. Identificación de Tipos: Lee los siguientes valores y clasifícalos: "Hola", 42, False, 9.99.
  2. Declaración Correcta: Abre Python IDLE o Google Colab. Crea 4 variables representando los datos de un dron (modelo, peso, rotores, cámara_activa) usando los tipos de datos correctos.
  3. Reglas de Nomenclatura: Intenta nombrar una variable empezando con un número (ej. 1erLugar = 10) en Python. Observa el error de sintaxis devuelto y explica por qué.
  4. Mutabilidad: En código, asigna score = 0. En la siguiente línea, cambia su valor a score = 100. Imprime la variable. Comprueba cómo la memoria reescribió el dato.
  5. Entrada de Datos: Usa el comando input() en Python para pedirle al usuario su nombre y guárdalo en una variable. Luego imprímelo en pantalla.
RA 2.2

Expresiones, Operadores Aritméticos y Relacionales

Glosario Técnico:

  • Operadores Aritméticos: Símbolos para hacer matemáticas: + (Suma), - (Resta), * (Multiplicación), / (División), % (Módulo/Residuo).
  • Operadores Relacionales: Comparan dos valores y siempre responden con Verdadero o Falso. == (Igual a), != (Diferente), > (Mayor que), < (Menor que).
  • Operadores Lógicos: AND (Y - Ambas deben cumplirse), OR (O - Al menos una se cumple), NOT (NO - Invierte el resultado).

Evaluación de Expresiones:

bateria = 80
temperatura = 35

# Operador Relacional (¿Es mayor?)
print(bateria > 50) # Devuelve True

# Operador Lógico AND (¿Tiene batería Y no está sobrecalentado?)
estado_ok = (bateria > 50) and (temperatura < 40)
print(estado_ok) # Devuelve True

5 Ejercicios Prácticos:

  1. Calculadora Básica: Crea un script que sume, reste, multiplique y divida dos variables numéricas, imprimiendo cada resultado.
  2. El Módulo (%): Divide 10 entre 3 usando el operador módulo (`10 % 3`). Explica por qué el resultado es 1 (El residuo). Es clave para saber si un número es par o impar.
  3. Comparación Estricta: Imprime el resultado de comparar 5 == "5" (Un entero contra un texto). Explica por qué en programación no son la misma cosa.
  4. Tabla de Verdad AND: En código, evalúa e imprime: True and True, True and False. Analiza los resultados lógicos.
  5. Sistema de Alarma (OR): Una alarma suena si (sensor_puerta == True) OR (sensor_ventana == True). Escribe la expresión en código y prueba cambiando los valores.
RA 2.2

Estructuras Condicionales y Selectivas

Glosario Técnico:

  • Estructura Condicional (If-Else): Es el cerebro de la toma de decisiones. Evalúa una condición (Verdadera/Falsa). Si es verdadera, ejecuta un bloque de código; si es falsa, ejecuta otro.
  • Condiciones Anidadas (Elif / Switch): Permiten hacer múltiples preguntas en cadena (Si no es esto... entonces ¿es esto otro?... si no, entonces esto).
  • Bloque de Código (Indentación): En Python, los espacios al inicio de la línea (sangría) definen qué código pertenece dentro del If. Si no indentas, el código se rompe.

El Portero Digital (If - Else):

edad_usuario = 16

if edad_usuario >= 18:
    print("Acceso concedido. Eres mayor de edad.")
else:
    print("Acceso denegado. Bloqueando sistema.")

5 Ejercicios Prácticos:

  1. Calificador Escolar: Pide al usuario su calificación (0-10). Si es mayor o igual a 7, imprime "Aprobado". Si no, imprime "Reprobado".
  2. Detector de Par/Impar: Pide un número. Usa el operador módulo (%). Si numero % 2 == 0, imprime "Es Par", sino, "Es Impar".
  3. Condicional Anidado (Elif): Crea un menú. Si la variable opcion es 1, imprime "Atacar". Si es 2, imprime "Defender". Si es 3, imprime "Huir". Usa if - elif - else.
  4. Juego de Contraseña: Define una variable clave_secreta = "1234". Pide un input al usuario. Usa un If para compararlos y darle acceso o rechazarlo.
  5. Error de Indentación: Escribe un If correcto, pero quítale los espacios de la siguiente línea. Ejecútalo, lee el error `IndentationError` y aprende a corregirlo.
RA 2.2

Estructuras Repetitivas (Ciclos For y While)

Glosario Técnico:

  • Bucle o Ciclo (Loop): Estructura que repite un bloque de código automáticamente sin que tengas que escribirlo 100 veces.
  • Ciclo For (Para): Ciclo Definido. Sabes exactamente cuántas veces quieres que se repita (ej. "Imprime esto 10 veces").
  • Ciclo While (Mientras): Ciclo Indefinido. Se repite infinitamente "mientras" una condición sea verdadera. Peligroso si no le pones un freno (Bucle Infinito).

Automatización (Loops):

# Ciclo FOR (Contando del 1 al 5)
for i in range(1, 6):
    print(f"Escaneando sector {i}...")

# Ciclo WHILE (Con cuenta regresiva para no ser infinito)
combustible = 3
while combustible > 0:
    print("Motor encendido")
    combustible = combustible - 1 # IMPORTANTE: El Freno

5 Ejercicios Prácticos (Entregables RA 2.2):

  1. El Castigo Escolar (For): Usa un ciclo for y la función range(100) para imprimir 100 veces la frase "No debo comer en el laboratorio de cómputo".
  2. Tabla de Multiplicar: Pide un número al usuario. Usa un ciclo for que vaya del 1 al 10 para imprimir la tabla de multiplicar de ese número.
  3. Bucle Infinito (Precaución): Escribe un ciclo while True: print("Crasheando sistema"). Ejecútalo y aprende a forzar la detención del entorno (Ctrl+C en la consola).
  4. Contador de Intentos (While): Crea un sistema que pida una contraseña. MIENTRAS la contraseña sea incorrecta, vuelve a pedirla. Si acierta, rompe el ciclo y salúdalo.
  5. Implementación Final (Modelado + Código): Diseña un pequeño juego de adivinar el número (del 1 al 10). Dibuja el diagrama de flujo y prográmalo usando If, Variables y un ciclo While. (Este es tu proyecto de RA 2.2).
